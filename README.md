# pandas_coffee_shop

Simple example project that demonstrates data processing for a coffee shop using pandas.

## Features
- Minimal data-processing demo using `pandas`.
- Example scripts in `project.py`.

## Requirements
- Python 3.8+
- See `requirements.txt` for exact dependencies.

## Setup
1. Create and activate a virtual environment:

```bash
python -m venv .venv
source .venv/bin/activate
```

2. Install dependencies:

```bash
pip install -r requirements.txt
```

## Run
Run the main script:

```bash
python project.py
```
